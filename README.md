# Last Mile Delivery Operation Analytics

## Project Overview

This project focuses on analyzing last mile delivery operations using SQL and MySQL. The analysis helps understand delivery demand, customer behavior, delivery performance, driver performance, and vehicle performance.

## Objectives

- Understand delivery demand
- Analyze customer behavior
- Evaluate delivery performance
- Analyze driver and vehicle performance
- Identify delivery problems
- Generate meaningful business insights

## Technologies Used

- MySQL
- SQL
- CSV datasets

## Database Tables

- Customers
- Orders
- Deliveries
- Drivers
- Vehicles

## Key Insights

The project analyzes delivery-related data to identify performance patterns, operational issues, and factors affecting last mile delivery efficiency.

## Conclusion

SQL-based analysis helps in understanding last mile delivery operations and supports better operational decision-making through data-driven insights.
